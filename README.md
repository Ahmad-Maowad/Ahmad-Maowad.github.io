# Ahmad Maowad — Urban Planning & GIS

Arabic and English professional portfolio. Built with Astro and Tailwind CSS from the MIT-licensed Astro Multilingual Portfolio template by nicremo.

## Source

The complete editable source is provided in `portfolio-source.zip`. Extract it into an empty directory, run `npm ci`, then `npm run dev` or `npm run build`.

The Pages workflow extracts this same archive, builds it, and publishes the generated static site. Updating the archive on the main branch redeploys the website.

Content: `src/i18n/`, `src/data/projects.json`, `src/data/experience.json`. Project media: `public/media/`. CV downloads: `public/cv/`.

Portfolio media is shown for professional presentation and is not licensed for third-party reuse. Confidential ownership records and detailed coordinate schedules are excluded. Template source attribution is retained in LICENSE.md and SOURCE.md inside the archive.
